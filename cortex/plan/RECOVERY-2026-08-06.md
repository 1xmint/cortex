## Frontend F2 (`a0e082fe`) — fully recovered

Three commits were on disk but unpushed. A fourth file, `RunsPane.tsx` (11,229 B),
was the agent's final `Write` and was never built or committed — the agent died in
between. The on-disk copy was verified byte-identical to the content in the
transcript, type-checks clean under `tsc -b`, and is now committed.

## Standing lesson

Unpushed commits in an agent worktree are invisible to every recovery path except
the reflog, and authored-but-uncommitted files survive only in the transcript.
An agent that produces durable output should push its branch as it goes, so that
losing the agent never means losing the work.
